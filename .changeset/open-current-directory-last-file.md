The default hotkey `Ctrl`+`Shift`+`H` (`Command`+`Shift`+`H` on Apple devices) now runs "Open current directory in terminal: Integrated" instead of the root command. "Open current directory in terminal" now works when no file is active, for example in a focused terminal, on an empty tab or in the graph view: it opens in the folder of the file you looked at last, or in the vault root when no file is open or recently opened, instead of showing a notice. Commands and menu items for one profile type, such as integrated, now open your default profile when it has that type, instead of the first profile of that type. (by [@janah01](https://github.com/janah01))
