The default profile and the order of the profile list now belong to each device. Choosing a default or moving a profile on one computer no longer changes them on your other computers. A default chosen on another platform no longer shows up as incompatible. The profiles themselves still sync. After the update, each device keeps the default it had. On a new device, choose the default profile again. (by [@janah01](https://github.com/janah01))
