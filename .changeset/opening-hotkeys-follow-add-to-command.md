"obsidian-terminal": patch
---

With "Add to command" off, a hotkey of a command that opens a terminal reaches the shell again when you press it in a focused terminal, as in 3.28.0. Before, the key did nothing. This also applies to the default `Ctrl`+`Shift`+`H` (`Command`+`Shift`+`H` on Apple devices). (by [@janah01](https://github.com/janah01))
