Commands and menu items for one profile type now open your default profile when it has that type and runs on this platform. This includes "Open current directory in terminal: Integrated" and its default hotkey `Ctrl`+`Shift`+`H` (`Command`+`Shift`+`H` on Apple devices). Before, they always opened the first profile of that type. (by [@janah01](https://github.com/janah01))
