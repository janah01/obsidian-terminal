Commands and menu items for one profile type now open your default profile when it has that type. This includes "Open root directory in terminal: Integrated" and its hotkey `Ctrl`+`Shift`+`H` (`Command`+`Shift`+`H` on Apple devices). Before, they always opened the first profile of that type. (by [@janah01](https://github.com/janah01))
